# User Stories — ProdOps University

User Stories no formato BDD (Behavior-Driven Development) com cenários **Given / When / Then**.

## Formato

```gherkin
Feature: <nome da funcionalidade>

  As a <papel>
  I want to <ação>
  So that <benefício>

  Scenario: <nome do cenário>
    Given <contexto inicial>
    When <ação executada>
    Then <resultado esperado>
    And <resultado adicional>
```
