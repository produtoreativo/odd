---

O caso central do livro é **Group Buying / Tuangou**, uma jornada de compra em grupo que atravessa PIM, catálogo, oferta, ordem de compra, pedido, faturamento e recebimento. Cada conceito do livro é demonstrado através desse caso para evitar exemplos artificiais e desconectados.

A sequência que governa o livro:

```
Intent → ODD → OBC → PRE → Delivery → Runtime → Outcome
```
